### 🧩 Problem-Solving Process

```text
Understand the Problem
        ↓
Study Constraints
        ↓
Think of a Brute Force Approach
        ↓
Analyze Time & Space Complexity
        ↓
Identify the Bottleneck
        ↓
Find a Better / Optimal Approach
        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
```

## 🔍 Problem-Solving Principles

### Understand Before Coding

Understand the problem, constraints, inputs, outputs, and expected behavior before starting implementation.

### Brute Force Before Optimization

Start with the simplest correct approach and then identify opportunities for improvement.

### Complexity Matters

Every important solution should consider:

- Time Complexity
- Space Complexity

### Dry Run

Manually trace the logic using examples and important edge cases.

### Learn From Mistakes

Mistakes are part of the learning process.

They may come from:

- Conceptual misunderstanding
- Pattern recognition
- Logic
- Implementation
- Complexity analysis
- Edge cases
- Recall
- Careless mistakes

### Revision

Previously learned concepts and problems are revisited through active recall and re-solving.
